# お役立ちコラム

- メイン `/#column` に7記事への入口、`/column` に一覧、`/column/[slug]` に静的記事ページを追加。
- 本文の編集・追加は `content/columns.ts`。`publishedAt` は実際の公開日を指定し、見かけ上の鮮度のためだけに変更しない。
- 7テーマ：ホームページの役割、制作前の準備、費用の考え方、Google検索・マップ、公開後の運用、制作会社向けの外注・制作パートナー、業務システム開発の外注。
- 2026-11-06: `website-outsourcing-partner` を先頭に追加。業務の切り分け、見積り資料、検収、納品・保守の分担を案内する。外注は個別見積りであり、一般向け初期費用の案内を外注単価にしない。守秘・実績掲載・情報共有の扱いは事前相談とし、架空の受託実績や対応保証を作らない。
- `audience: "partners"` の記事は制作会社向けの相談文言と制作見本へのリンクを表示。既存の一般向け記事の相談案内は維持。
- 2026-11-06: `business-system-outsourcing` を先頭に追加。顧客・予約・在庫・備品・請求書・シフトなどの業務例、既存サービスの活用、API連携、要件定義、検収・運用の分担を説明。業務例を実績や完成済み商品として扱わず、対応可否・費用・保守は個別確認とする。相談時に個人情報・本番データ・認証情報を送らせない。
- `audience: "systems"` は企業・制作会社向けの開発相談と、`siteConfig.owner.portfolioUrl`（gutae.dev）へのリンクを表示。ホームページ外注記事との相互リンクを維持。
- 記事は全文をサーバー側で出力。目次・関連記事・相談先は通常のリンクで、JavaScriptなしでも読める。
- 記事ごとのタイトル・説明・canonical・OG画像、BlogPostingとパンくず構造化データ、サイトマップを連動。
- 著者はまちのWeb。架空の専門家・実績・順位保証は使わない。検索に関する説明にはGoogle公式情報へのリンクを付ける。
- 料金の数字は記事内に重複させず、最新の料金案内へ誘導。問い合わせフォーム・追加機能の見積り方針を維持。
- サムネイルはブランドの配色に合わせたコード製の独自イラスト。人物写真や汎用ストック写真は使わない。

確認：`npm run build` の後に `node --test scripts/test-columns.mjs`。既存の回帰テストも実行。320px/390pxの一覧・記事、記事内目次、関連記事、メインへの戻り先をブラウザ確認。
