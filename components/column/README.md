# お役立ちコラム

- メイン `/#column` に5記事への入口、`/column` に一覧、`/column/[slug]` に静的記事ページを追加。
- 本文の編集・追加は `content/columns.ts`。`publishedAt` は実際の公開日を指定し、見かけ上の鮮度のためだけに変更しない。
- 5テーマ：ホームページの役割、制作前の準備、費用の考え方、Google検索・マップ、公開後の運用。
- 記事は全文をサーバー側で出力。目次・関連記事・相談先は通常のリンクで、JavaScriptなしでも読める。
- 記事ごとのタイトル・説明・canonical・OG画像、BlogPostingとパンくず構造化データ、サイトマップを連動。
- 著者はまちのWeb。架空の専門家・実績・順位保証は使わない。検索に関する説明にはGoogle公式情報へのリンクを付ける。
- 料金の数字は記事内に重複させず、最新の料金案内へ誘導。問い合わせフォーム・追加機能の見積り方針を維持。
- サムネイルはブランドの配色に合わせたコード製の独自イラスト。人物写真や汎用ストック写真は使わない。

確認：`npm run build` の後に `node --test scripts/test-columns.mjs`。既存の回帰テストも実行。320px/390pxの一覧・記事、記事内目次、関連記事、メインへの戻り先をブラウザ確認。
