# 相談からはじめる制作・運用の案内

2026-10-27更新。プラン比較ではなく、基本構成の初期制作費0円〜・月額運用費5,500円〜（税込）と、相談後の個別見積りを案内。

- `/#demo`: 最近制作した8サイトを業種別に紹介。旧3テンプレートのリンクはメインから除外。旧URLは互換性のため維持。
- `/#website-examples`: ネイティブ横スクロール。タッチ、前後ボタン、トラック上の←/→/Home/Endに対応。自動再生なし。
- `/#price`: 初期費用と月額費用の目安、制作・運用の対応内容、別途見積りの追加機能、LINEとフォームへの相談導線。
- 画像・リンクは `site.config.ts` の `websiteExamples` で共有。人物を除いた最新画像を維持し、人物写真を残した美容室のみ例外。
- 初期0円は基本構成の場合。独自デザイン・演出・フォーム・複数ページ・予約/決済連携・システム開発は必要に応じて追加見積り。すべてが最低料金で提供されるという表示はしない。
- 範囲・分類・初期費用は `lib/example-offers.ts` で一元管理。ギャラリーは「すべて / 初期0円の制作例 / 追加制作費のある例」で絞り込みでき、各カードに基本範囲・追加範囲を表示する。サンプル内の大きな制作費案内は削除し、価格・比較はメインサイトに集約する。
- 初期0円の制作例はSUMITOKI・SUI・こもれび・SEKKAの4件。既存の1ページ構成と演出を活用し、提供原稿・写真を掲載する場合が対象。KASANE・凪・みちる・NIWATOは追加制作を相談する例として区別する。KASANE・凪・NIWATOも紹介のみの基本1ページなら初期0円から相談可能。
- 外部予約サイト・LINE・既存決済ページ等への単純なリンク設置は基本範囲。実際の予約管理・フォーム送信・自動SNS連携・決済システム構築とは区別する。
- MICHIRUはトップ・コース／月謝・体験／お問い合わせの実際の3ルート構成。初期55,000円〜（税込）＝下層2ページ33,000円＋標準フォーム・メール通知22,000円を目安とし、初期0円の対象外。月額5,500円〜は別途。操作見本のフォームは固定サンプル＋選択項目だけで、個人情報の入力・送信・予約・保存は行わない。
- 最低契約期間3ヶ月、お知らせ更新、年4回のリニューアル更新など、従来の運用条件は維持。
- ヒーロー、SEOメタ情報、OG画像、構造化データ、特商法ページも新しい料金表示に同期。
- 支払方法はStripeのカード決済と銀行振込。料金欄・FAQ・特商法は `site.config.ts` の `payments` を共有し、プライバシーポリシーにも決済先を明記。
- 顧客ごとに見積金額が異なるため、サイト共通の決済ボタンやカード入力フォームは置かない。契約後、Stripe側で顧客別の請求書／定期支払いを作成して専用リンクを送る運用。API・秘密鍵・Webhook・実決済リンクは追加していない。Stripe側での本人確認、決済方法・請求周期などの設定とテストは別途必要。

検証: `npm run build` の後、`node --test scripts/test-consultation-pricing.mjs` と既存デモの回帰テスト。ブラウザで320px・390px・デスクトップの表示とスクロール、相談先を確認。

## 追加制作の体験を強化（2026-10-26）

初期0円の4デモ・料金・対応範囲は変更しない。追加制作の4カードのみ `offer.upgrade` を持ち、3つの追加ポイントと機能への直接リンクを表示する。追加制作フィルターには基本1ページとの違いを説明する導入を表示。

- KASANE: 独立した2つのプロジェクトストーリー。課題・提案・素材パレットと、事例間・相談への導線。
- 凪: `/demo/nagi/stay`。過ごし方2種・1/2泊・固定大人2名の参考金額と旅程が連動。空室照会・予約ではない。
- みちる: コースページに簡易ガイド。学年に基づくコースと経験・希望に応じた説明。コースIDのみを問い合わせページに引き継ぐ。55,000円〜の価格は維持。正式なクラス分け・入会受付はしない。
- NIWATO: `/demo/niwato/member`。訪問日変更、2件の作業レポート、プラン変更の確認、明細表示、休止/再開をローカル状態だけで体験。ログイン・個人データ・送信・保存・課金なし。実運用には認証・バックエンド・決済等の別途設計が必要。

すべてnoindex、サイトマップ非掲載。新しい人物画像・外部API・実決済・会員認証は追加しない。`scripts/test-paid-upgrades.mjs` で範囲・計算・ガイド・ルート・非送信の境界を確認。

## サンプル内の制作費案内を削除（2026-10-27）

全サンプルと下層ページから「この見本でできること、費用のこと。」の営業用セクションを削除。削除先へ向いていた上部リンクも業種・ブランドの短いラベルに置き換える。料金データ・メインカード・無料/有料の区分・機能体験リンクは変更しない。架空情報である旨の小さなフッター表示と、フォーム・予約・決済の操作境界は維持する。
