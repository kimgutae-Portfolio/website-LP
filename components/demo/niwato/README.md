# NIWATO — 月額の芝生ケア・販売サイト見本

ローカルプレビュー: http://localhost:3000/demo/niwato

Noto Sans JP、深い緑・明るい芝色・白を軸にした、架空の定期サービスブランドです。LP の制作イメージにもリンクを追加しています。既存のデモ・連絡先・料金プランは変更していません。

## 表現と体験

- 3枚の面が開く短いオープニング。写真の緩やかな視差、セクション登場演出。動きを減らす OS 設定では停止します。
- 同じ庭の生成画像を元に編集した Before / After。タッチ・マウス・キーボードで比較できるネイティブスライダー。
- 面積 30 / 60 / 100㎡、訪問 月1 / 月2回で、税込月額が連動。全6パターン。
- 含む作業と対象外の作業、冬の訪問内容、架空の訪問エリア、FAQ、写真付き作業レポートの見本。
- モバイル固定バー、メニュー、季節タブ、キーボード操作可能なダイアログ。
- `/demo/niwato` は noindex。独自 favicon 付き。サイトマップへの追加なし。

## 決済はシミュレーションのみ

プラン選択 → 月額・更新条件の確認 → 入力不要のデモカード → 確認チェック → 体験完了。

**カード情報・氏名・住所などの入力欄はありません。ネットワークへの申込送信、カード情報の保存、課金、契約、訪問手配、メール送信はありません。** 実際に販売する場合は、決済事業者との接続、顧客管理・請求・解約の運用、販売条件と必要な法定表示などを別途設計してください。本デモの料金や条件は実際のサービスや法的文書ではありません。

## 画像と最終プロンプト

内蔵 **image_gen** ツールでオリジナル写真を3点生成し、同じ庭の写真を編集して After を1点制作。いずれも架空イメージで施工実績ではありません。

- ヒーロー: `public/demo/niwato/hero.webp`
- 作業風景: `public/demo/niwato/care.webp`
- 比較前: `public/demo/niwato/before.webp`
- 比較後: `public/demo/niwato/after.webp`
- 全プロンプト、元ファイルパス、比較画像の参照関係: `scripts/demo-niwato-assets.json`
- 再変換: `node scripts/prepare-niwato-assets.mjs`（元生成ファイルが残っている環境のみ）

WebP 1536px・品質86でプロジェクト内に保存。外部画像サービスへの依存はありません。

## 検証

`npm run build` の後に `node --test scripts/test-niwato.mjs`。料金全パターン・無効値・決済情報を扱わない構造・画像・SSR・リンク・動きを減らす設定を検証します。ブラウザではモバイル / タブレット / デスクトップ、スライダー、プラン変更、チェック前のボタン無効化、体験完了、閉じる・再度開く動作を確認します。

2026-10-22: 最終ビルド成功。NIWATO 8件と既存デモ39件、合計47件すべて合格。ブラウザで320 / 352 / 390 / 768 / 1440pxを確認し、横方向のページはみ出しなし。写真比較のドラッグ・Home/End、季節タブのHome、メニュー・FAQ・レポート、プラン変更、申込条件確認前後のボタン状態、体験完了後のリセットを確認済みです。
