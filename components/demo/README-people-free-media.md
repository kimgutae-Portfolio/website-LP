# 人物を写さない写真への更新

2026-10-22。美容室の人物写真は維持し、それ以外の生成写真から人物・手・身体の一部を除去。内蔵 `image_gen` で元画像を編集し、構図・色・空間の雰囲気はできるだけ保持しています。

## 対象

- KASANE: メイン空間の奥の人物、素材選定テーブルのスタッフと手。
- SUMITOKI: 炭火写真の腕・手・トング。食材を焼き網に置いた写真へ。
- MICHIRU: メイン写真の先生と子ども、教材写真の手、講師写真の人物。教室・教材・レッスン準備の風景へ。
- SEKKA: 検査写真の手。検査台の測定器と金属部品へ。
- NIWATO: 芝刈り機の作業者。庭と停めた芝刈り機の写真へ。

合計8点。KASANE / SUMITOKI の12秒の写真フィルム2本も、編集後の写真から再制作。画像説明、メインページのサムネイル、SNS共有用画像も更新しています。イラストの人物やクリニックの動物キャラクターは変更していません。

## 保存先とプロンプト

すべて `public/demo/<ブランド>/<名前>-no-people.webp` に保存。フィルムは `brand-film-no-people.mp4` / `photo-film-no-people.mp4`。新しいファイル名により古い画像キャッシュの再表示を防ぎます。元ファイルは非表示の制作素材として残し、美容室の画像・動画は一切変更していません。

完全な最終プロンプト、生成元・編集対象・出力パス、フィルムの使用画像、美容室メディアの変更前ハッシュは `scripts/demo-people-free-assets.json` に記録。

再変換: `node scripts/prepare-people-free-media.mjs`。再変換には記録された元生成ファイルが必要です。

検証: `npm run build` の後に `node --test scripts/test-people-free-media.mjs`。画像サイズと形式、参照切り替え、メインサムネイル、説明文、フィルム参照、美容室ファイルのハッシュ一致を確認します。

更新時の検証: ビルド成功・既存47件と画像更新6件の合計53件が合格。モバイルで変更した写真8点を確認し、KASANE / SUMITOKI の更新後フィルム（各12秒）の読み込み・再生を確認しました。NIWATO の写真は人物の位置から芝刈り機へ表示位置を調整しています。
